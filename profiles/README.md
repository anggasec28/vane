# VANE Specialist Profile Catalog

This directory contains repository-side specialist role contracts. A role profile does not create a Hermes session and does not grant tool access. Hermes-specific profile loading, session spawning, MCP discovery, compatibility, and runtime tests remain the responsibility of the operator's Hermes agent.

VANE Master owns scope, authorization, dispatch, and final decisions. Specialist roles analyze supplied artifacts, plan authorized work, correlate evidence, and recommend next steps. A discovered asset, dependency edge, redirect, or worker handoff never grants scope. Tool permissions are assigned separately by central enforcement and host configuration. Specialists cannot approve their own work or access signing material. Independent validation remains separate from the analyst producing the assessment.

Every profile defines identity, mission, responsibilities, required inputs, allowed activities, prohibited activities, output contract, handoff, and stop conditions. Actual loading by Hermes has not been verified.
