# VANE Specialist Profile Catalog

VANE is the single primary agent profile distributed in this repository and runs on the native Hermes Agent runtime. The root Hermes profile configuration, identity artifact, skills, and governed engine integration define VANE. This directory contains subordinate specialist role contracts only.

Master is the human operator who interacts directly with VANE through Telegram. Master is not an AI agent, Hermes profile, sub-agent, or separate runtime. Master retains ultimate authority over scope, approvals, protected identity, and final decisions. VANE owns orchestration and may dispatch bounded specialist work only within effective authority and policy.

A role profile does not create a Hermes session and does not independently grant tool access. Hermes-specific profile loading, session spawning, MCP discovery, compatibility, and runtime tests remain the responsibility of the operator's Hermes agent.

Specialists analyze supplied artifacts, plan and perform only authorized work through separately governed capabilities, correlate evidence, and recommend next steps. A discovered asset, dependency edge, redirect, or worker handoff never grants scope. Tool permissions are assigned separately by central enforcement and host configuration. Specialists cannot approve their own work or access signing material. Independent validation remains separate from the analyst producing the assessment.

Every profile defines identity, mission, responsibilities, required inputs, allowed activities, prohibited activities, output contract, handoff, and stop conditions. Actual loading by Hermes has not been verified.
