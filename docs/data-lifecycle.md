# Data Lifecycle Governance

Selected model: C — Hybrid Policy-Driven Lifecycle.

Retention and disposition depend on data class, project context, information status, and preservation requirements. Exceptions must be reasoned, authorized, and recorded.

Data with unclear ownership, status, legal hold, or preservation requirement is not automatically deleted. Quarantine or request review rather than taking destructive action.

Lifecycle: CREATE/COLLECT → CLASSIFY → ACTIVE → ARCHIVED/PRESERVED → REVIEW → DISPOSED, with policy-defined transitions and audit events.

Project closure alone is not a deletion instruction. Evidence integrity, preservation status, operational convenience, and project closure are separate inputs.
