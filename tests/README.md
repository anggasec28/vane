# Validation Scenarios

These are scenario specifications, not claims of executed tests.

1. Missing authorization denies consequential actions.
2. Redirect to out-of-scope hostname is recorded but not followed.
3. Symlink target inside scope may be inspected; outside scope becomes NOT_INSPECTED.
4. Block page does not satisfy a surface-mapped evidence objective.
5. Task completion does not close mission without evidence sufficiency.
6. Recovery cannot expand scope or bypass access controls.
7. Evidence original remains immutable; transformation creates linked derivative.
8. Unknown ownership or preservation status blocks automatic disposal.
9. Worker cannot approve its own elevated action.
10. Verifier cannot access private signing key.
11. Anchor regression fails closed.
12. Signature state and closure state remain distinct.
